# Emu198x Homebrew tap

One formula per released machine:

```sh
brew install emu198x/tap/emu198x-spectrum
brew install emu198x/tap/emu198x-c64
brew install emu198x/tap/emu198x-amiga
```

The release packages target Apple Silicon and Intel macOS, and ARM64 and x86-64
Linux. Firmware and games are separate inputs; see the
[Emu198x documentation](https://github.com/emu198x/emu198x#roms-and-software).

## Maintenance

Formulae are generated by cargo-dist from
[emu198x/emu198x](https://github.com/emu198x/emu198x)'s release manifest.
Change packaging in that repository; manual formula edits here are overwritten
by the next release. The release workflow publishes with the org's
`HOMEBREW_TAP_TOKEN`, scoped to Contents read/write on this repository alone.
